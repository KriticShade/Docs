# Contrôle Interne SSI – Approche Méthodologique

---

## 📋 Ma lecture de ta situation

Tu as deux typologies de postes :
- **PC Internet** → poste à risque élevé, développeurs avec droits admin locaux
- **PC Restreint (admin)** → surface d'attaque réduite mais vérification manuelle nécessaire

Tu as déjà un script de collecte. Il faut maintenant **structurer tout ça proprement**.

---

## 1. LA NOTE DE CONTRÔLE INTERNE – Structure type

---

### 📄 En-tête obligatoire

```
CLASSIFICATION : [Interne / Confidentiel]
Référence      : SSI-CTR-2026-XX
Version        : 1.0
Date           : 16/06/2026
Rédacteur      : [CSSI / RSSI]
Destinataires  : Direction, RH, Managers, DSI
Objet          : Contrôle interne de conformité SSI des postes de travail
```

---

### 📌 SECTION 1 – Contexte et justification (le "pourquoi")

```
1.1 Cadre réglementaire et politique interne
1.2 Objectifs du contrôle
1.3 Périmètre concerné
1.4 Base juridique et information des utilisateurs
```

**Ce que tu dois écrire concrètement :**

> *"Dans le cadre de la Politique de Sécurité des Systèmes d'Information (PSSI) 
> de [Organisation], et conformément aux dispositions de [RGS / LPM / RGPD / 
> votre charte informatique], il est procédé périodiquement à des contrôles 
> techniques et fonctionnels des postes de travail.*
>
> *Ces contrôles visent à s'assurer de la conformité des usages, de l'intégrité 
> des configurations et de l'absence de comportements à risque ou de compromission.*
>
> *Les utilisateurs ont été informés de cette possibilité de contrôle via 
> [la charte informatique signée / note de service N°XX du JJ/MM/AAAA]."*

> ⚠️ **Point critique** : la base juridique doit être béton.
> Sans charte signée ou note préalable, tu exposes l'organisation.

---

### 📌 SECTION 2 – Périmètre et population concernée

```
┌─────────────────────┬──────────────────┬─────────────────────┐
│ Type de poste       │ Population       │ Niveau de risque    │
├─────────────────────┼──────────────────┼─────────────────────┤
│ PC Internet         │ Développeurs     │ ÉLEVÉ               │
│ PC Restreint Admin  │ Personnel admin  │ MODÉRÉ              │
└─────────────────────┴──────────────────┴─────────────────────┘

Nombre de postes concernés : XX
Période de contrôle        : du JJ/MM au JJ/MM/2026
```

---

### 📌 SECTION 3 – Modalités opérationnelles (le "comment")

**3.1 Mode de réalisation**

```
→ Contrôle à distance via script automatisé (PC Internet)
→ Contrôle manuel sur site (PC Restreint)
→ Entretien utilisateur possible si anomalie détectée
→ Présence du manager : OUI / NON (à définir)
```

**3.2 Calendrier**

```
┌──────────────────────────────┬─────────────────┐
│ Étape                        │ Date / Délai     │
├──────────────────────────────┼─────────────────┤
│ Information des utilisateurs │ J-15             │
│ Collecte technique           │ Semaine XX       │

│ Plan de remédiation          │ J+20             │
└──────────────────────────────┴─────────────────┘
```

**3.3 Confidentialité des résultats**

> Les résultats individuels sont confidentiels et destinés uniquement
> au RSSI, au CSSI et à la Direction. Toute anomalie grave fait l'objet
> d'une procédure séparée impliquant les RH et la direction juridique.

## 2. CE QUE TU CONTRÔLES – Référentiel complet

---

### 🖥️ PC INTERNET – Développeurs (priorité haute)

#### A. Ce que ton script fait déjà ✅

```
✓ Historique navigateur
✓ Extensions navigateur
✓ Registre connexions périphériques (USB, etc.)
✓ Applications installées
```

#### B. Ce que tu peux AJOUTER au script 🔧

**→ Niveau système**
```powershell
# Comptes locaux et droits admin
Get-LocalGroupMember -Group "Administrateurs"

# Services en cours / inhabituels
Get-Service | Where-Object {$_.Status -eq "Running"} | 
  Select-Object Name, DisplayName, StartType

# Tâches planifiées (persistence malware)
Get-ScheduledTask | Where-Object {$_.State -ne "Disabled"} |
  Select-Object TaskName, TaskPath, State

# Connexions réseau actives (exfiltration ?)
netstat -ano

# Partages réseau ouverts
Get-SmbShare

# Dernières connexions / sessions
Get-EventLog -LogName Security -InstanceId 4624,4625,4648 -Newest 100
# 4624 = connexion réussie
# 4625 = échec connexion  
# 4648 = connexion avec credentials explicites

# Autorun / démarrage
Get-CimInstance Win32_StartupCommand

# Processus en cours avec chemin d'exécution
Get-Process | Select-Object Name, Id, Path, CPU | Sort-Object CPU -Desc
```

**→ Niveau sécurité**
```powershell
# État de l'antivirus
Get-MpComputerStatus | Select-Object AMRunningMode, 
  AntivirusEnabled, RealTimeProtectionEnabled,
  AntivirusSignatureAge, LastFullScanTime

# Pare-feu
Get-NetFirewallProfile | Select-Object Name, Enabled

# Chiffrement disque BitLocker
Get-BitLockerVolume | Select-Object MountPoint, 
  VolumeStatus, ProtectionStatus

# Mises à jour manquantes
Get-HotFix | Sort-Object InstalledOn -Descending | Select-Object -First 10

# Politique de mot de passe locale
net accounts
```

**→ Niveau développeur spécifique** ⚡
```powershell
# Outils de dev installés (à croiser avec liste autorisée)
$devsTools = @("git","docker","python","nodejs","npm",
               "winscp","putty","filezilla","wireshark",
               "nmap","netcat","burpsuite","postman")

foreach ($tool in $devsTools) {
    $found = Get-Command $tool -ErrorAction SilentlyContinue
    if ($found) { Write-Output "[DÉTECTÉ] $tool : $($found.Source)" }
}

# Clés SSH présentes
Get-ChildItem "$env:USERPROFILE\.ssh\" -ErrorAction SilentlyContinue

# Fichiers .env, credentials en clair (risque secret leakage)
Get-ChildItem C:\Users -Recurse -Include "*.env","*.pem","*.key",
  "credentials*","*password*","*secret*" -ErrorAction SilentlyContinue |
  Select-Object FullName, LastWriteTime

# Dépôts Git locaux (code source potentiellement sensible)
Get-ChildItem C:\Users -Recurse -Filter ".git" -Directory |
  Select-Object FullName
```

**→ Niveau réseau / VPN**
```powershell
# Interfaces réseau et config
Get-NetIPConfiguration

# Connexions VPN configurées
Get-VpnConnection

# Proxy configuré
netsh winhttp show proxy
Get-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\
  Internet Settings" | Select-Object ProxyEnable, ProxyServer
```

#### C. Vérifications MANUELLES complémentaires 👁️

```
□ Bureau et téléchargements : fichiers sensibles en clair ?
□ Navigateur : mots de passe enregistrés (vérif politique)
□ Stockage cloud sync (OneDrive, Google Drive, Dropbox installé ?)
□ Client mail externe configuré ?
□ Outils d'accès distant non autorisés (AnyDesk, TeamViewer...)
□ Virtualisation locale (VirtualBox, VMware) → shadow IT
□ WSL (Windows Subsystem for Linux) activé ?
□ Conteneurs Docker actifs ?
□ Accès GitHub/GitLab : dépôts publics ? clés déployées ?
```

---

### 🖥️ PC RESTREINT – Vérification manuelle

```
□ Compte utilisateur correct (pas de compte admin résiduel)
□ Politique d'écran de veille (≤ 10 min avec MDP)
□ Pas de post-it avec credentials visibles (oui ça arrive)
□ Périphériques USB connectés / autorisés
□ Pas de logiciel installé en dehors du catalogue
□ Mises à jour système à jour
□ Antivirus actif et à jour
□ Aucun accès internet non filtré
□ Profil utilisateur conforme au besoin métier (moindre privilège)
```
